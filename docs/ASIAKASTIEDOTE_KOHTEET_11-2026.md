# Asiakastiedote: Kohteet-sivun uudistus (luonnos)

Lähetä tuotantoon viennin jälkeen sivulta **Asetukset → Asiakastiedotteet**. Vastaanottajiksi
"Kaikki asiakkaiden käyttäjät", asiakkaat: ei valintoja (kaikki aktiiviset). Lähetä ensin testi itsellesi.
`{yritys}` korvautuu asiakkaan nimellä.

**Aihe:**

Kohteet-sivu uudistui: näet nyt profiiliisi sopivat taloyhtiöt

**Viesti:**

```
Hei {yritys},

FlowLeadsin Kohteet-sivu on uudistunut. Näet nyt ne taloyhtiöt, joissa urakkasi remontti on päätetty tai suunniteltu ja alkaa tänä vuonna tai kahtena seuraavana. Pidemmälle tulevaisuuteen ajoittuvat ja aikataulultaan auki olevat kohteet eivät enää täytä listaa, paitsi jos aikataulua ei tiedetä lainkaan.

Uutta on myös:

- Jokaisella rivillä lukee, miksi kohde näkyy, esimerkiksi "Putkiremontti päätetty, alkaa 2027 · isännöitsijän puhelin ja sähköposti tiedossa".
- Taloyhtiöt, joilla remontti on vasta tarve eikä sitä ole päätetty, löytyvät listan alta Ennakoi-osiosta. Niistä saa hyviä yhteydenottoja ennen kuin hanke alkaa.
- Saman taloyhtiön ilmoitukset näkyvät yhtenä kohteena.
- Harvemmin tarvitut hakuehdot ovat nyt "Lisää hakuehtoja" -kohdan takana.
- Liidien vienti (CSV ja CRM-tiedostot) on pääkäyttäjien toiminto.

Voit muuttaa aikaikkunaa kohdassa Asetukset → Urakat ja kohdehaku ("Remontti alkaa enintään näin monen vuoden päästä"). Tyhjä kenttä näyttää kaikki vuodet.

Jos jokin ei toimi niin kuin odotat, vastaa suoraan tähän viestiin.

Terveisin
FlowLeads
```
